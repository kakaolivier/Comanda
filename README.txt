COMANDA DIGITAL — HTML

Abra index.html no navegador ou use Live Server no VS Code.

Agora todas as páginas possuem uma guia de navegação para acesso rápido:
Login | Cadastro | Cozinha | Mesas | Novo pedido

Fluxo demonstrativo:
- Login -> Painel da Cozinha
- Mesas -> seleção/abertura de comanda
- Novo pedido -> adiciona itens, calcula total e envia para cozinha
- Cadastro -> cadastro de usuário

Observação: os dados são apenas demonstrativos e ficam no localStorage do navegador.
